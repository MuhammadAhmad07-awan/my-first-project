Web 3.0

Assignment 1 · CLO1

1. Introduction

Web 3.0 is a concept of a more decentralized, intelligent and connected web. It focuses on better data sharing, user control and decentralized services.

2. History

Web 1.0

Mostly static websites. Users mainly read information.

Web 2.0

Interactive websites, social media and user-created content.

Web 3.0

Focuses on decentralization, connected data and digital ownership.

3. Technologies

  • Blockchain: Distributed digital ledger.
  • Smart Contracts: Programs that run predefined rules on a blockchain.
  • Artificial Intelligence: Helps systems process information intelligently.
  • Semantic Data: Connects information so computers can understand relationships.

4. Languages

  • HTML — Structure of web pages
  • CSS — Design and layout
  • JavaScript — Interaction and functionality
  • Solidity — Smart contract development

5. Tools

VS Code, Web Browser, Git/GitHub and Remix IDE are commonly used tools for development and testing.

6. Implementation

  1. Plan the website or application.
  2. Build the interface using HTML, CSS and JavaScript.
  3. Connect required APIs or decentralized services.
  4. Test HTML tags, CSS and browser behavior.

7. Web 1.0, Web 2.0 and Web 3.0

Feature Web 1.0 Web 2.0 Web 3.0
Main idea Read Read + Write Read + Write + Own
Content Static User-generated Connected / intelligent
Control Website owners Large platforms More distributed
Technology HTML JS, APIs, databases Blockchain, AI
